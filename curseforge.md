# BedrockPlacing

Never aim at the edge again. Stand on a block, look straight ahead and right-click the air: the block lands on the side of the floor you stand on, in the direction you face, just like Bedrock placing. A white outline shows exactly which cell gets filled, and holding right-click bridges fast without vanilla's slow repeat delay.

![A long cobblestone bridge built straight out over open ground](https://wiki.mycelium-gg.org/bedrockplacing/img/bridge.jpg)

- Same-layer lock: jumping or falling never strands a block off your floor
- Works in multiplayer, with the server checking every placement
- Sneak-to-disable, reach, preview and repeat speed are all configurable

![The white outline previews the next block next to the floor](https://wiki.mycelium-gg.org/bedrockplacing/img/preview.jpg)

## Install

Install it on both client and server. Vanilla clients can still join and place blocks the normal way.

Requires [Mycel](https://www.curseforge.com/minecraft/mc-mods/mycel): install it alongside this mod. Minecraft 26.1, 26.2 and 26.3 on Fabric, Forge and NeoForge, Java 25. On Fabric you also need Fabric API.

Every setting and command is on the [wiki](https://wiki.mycelium-gg.org/bedrockplacing/).
